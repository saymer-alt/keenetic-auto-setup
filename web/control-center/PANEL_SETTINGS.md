# Настройки панели

Отдельный необязательный компонент. IPK не устанавливается вместе с обычным KAS.
[Установка и удаление пакета](packaging/README.md).

**В опубликованной beta.4** новая IPK-установка слушает только Home IPv4 на порту **8081**.
**Beta.6** слушает все IPv4 роутера на порту **18080**, если сохранённые настройки отсутствуют; при конфликте `EADDRINUSE` пробует 18081–18090, включая loopback для
обычного KeenDNS. Доступ на WAN разрешают или запрещают существующие правила KeeneticOS;
KAS WEB сам не открывает входящие порты. Опция «Только домашняя сеть» по умолчанию выключена.
Новая ручная установка
через `kas-web-manage.sh` также использует **18080** (старые сохранённые порты сохраняются); сохранённая настройка порта
приоритетнее обоих значений. IPK намеренно не перезаписывает ручную установку.

В «Настройках» независимы ограничение Home и авторизация. Ограничение Home выключено
по умолчанию. Без него доступ из других подсетей определяется маршрутизацией/firewall;
панель не открывает порты на WAN и не меняет правила роутера.

Авторизация: выключена / отдельный пароль панели (логин `kas`) / текущая учётная
запись Entware (логин `root`). Для включения Entware нужно подтвердить действующий
пароль; KAS не сохраняет и не меняет системный пароль. Пароль KeeneticOS `admin` —
другая учётная запись. В отдельном режиме пароль 12–128 байт, в хранилище сохраняется
солёный versioned SHA512crypt, не исходный пароль. HTTP Basic сам по себе не шифрует
пароль: используйте доверенную сеть, VPN или уже настроенный HTTPS-прокси роутера.

При смене настроек защищённой панели требуется текущий пароль, даже если браузер
уже авторизован. Пустой новый пароль сохраняет имеющийся только в режиме `kas`.
После смены пароля браузер может вновь запросить логин. Если меняется порт, панель
сначала занимает новый сокет, затем сохраняет настройки и возвращает новый адрес.
При занятом порте или ошибке записи старый адрес остаётся доступным. Никакой другой
сервис не останавливается. При успешно сменённом порте используйте показанную ссылку.

Настройки сохраняются приватно в `/opt/etc/kas-control-center.settings.json` (0600).
Не редактируйте файл одновременно с операциями панели. Ошибочный/небезопасный файл
блокирует запуск, а не молча отключает авторизацию. Пароль/его хеш никогда не
возвращаются API настроек. Секреты не сохраняются в browser storage.

Проверки: Go API + реальные TCP-слушатели (конфликт, ошибка записи, смена адреса),
root shadow/passwd и отзыв кэша при блокировке пользователя, race, Chromium с
санитизированными API fixtures, реальный Entware opkg с offline-root. Workflow
`web-settings-emulated.yml` запускает Go-тесты ARM64/MIPSel под QEMU user: это
эмуляция CPU/Linux-вызовов, не полная прошивка Keenetic. Отдельные native workflows
проверяют существующие импорт/фильтр/lifecycle в гостевой KeeneticOS; их прежние
результаты не объявляются новыми тестами IPK на физическом роутере.
