# Что такое MetaCubeX

Вопрос этой статьи: **«Что такое MetaCubeX и почему он появляется рядом с Mihomo?»**

Центральный тезис, ради которого статья написана:

> **MetaCubeX ≠ Mihomo.**
> Mihomo — ядро: оно выполняет сетевую работу (принимает и маршрутизирует трафик).
> MetaCubeX-панель — web-интерфейс: показывает состояние ядра и отправляет команды
> через его API. Панель сама не маршрутизирует ни один байт вашего трафика.

---

## Сначала аккуратно со словом «MetaCubeX»

Слово «MetaCubeX» означает не одну вещь, и из-за этого возникает путаница:

- **MetaCubeX** — это организация/проект в экосистеме: репозиторий самого ядра
  (`MetaCubeX/mihomo`), официальная веб-панель **metacubexd**, гео-базы для правил
  (`meta-rules-dat`) и другое (*официальные репозитории на GitHub*).
- В разговорах «открой MetaCubeX» почти всегда означает именно **веб-панель**.
- Конкретных панелей несколько, и это разные проекты:
  - **metacubexd** — официальная панель MetaCubeX;
  - **yacd-meta** — панель из организации MetaCubeX;
  - **zashboard** — сторонняя панель (проект Zephyruso; к организации MetaCubeX
    отношения не имеет).

В статьях этой энциклопедии «MetaCubeX» = веб-панель, а если важна конкретика —
названа по имени. В этом проекте в примере `external-ui-url` из статьи 12 ставится
именно **metacubexd** (**Проверено в проекте**: URL в конфиге пакета и в статье 12).

---

## Кто что делает

```text
Mihomo
= ядро
= выполняет сетевую работу: принимает трафик, применяет правила, отправляет дальше

MetaCubeX (панель)
= web-интерфейс
= показывает состояние и отправляет команды через API ядра
```

Панель живёт в браузере (как страница) или раздаётся самим ядром как статические
файлы — в обоих случаях это просто интерфейс. Выключите роутер — панель исчезнет;
выключите панель — Mihomo продолжит маршрутизировать трафик.

---

## Что умеет панель

Типовые возможности (перечислено по поведению панелей metacubexd / zashboard /
yacd-meta — *общее поведение, по их коду и описаниям; набор зависит от конкретной
панели и версии*):

- **показать proxies** — список серверов из `proxies` вашего конфига;
- **показать proxy-groups** — группы и выбранный в каждой узел;
- **показать connections** — живые соединения: что куда идёт и через какой выход;
- **показать логи/статус** — то, что ядро отдаёт через API;
- **выполнять операции управления** — если controller/API это разрешает: переключить
  узел в группе, перечитать конфиг и т.п.

Ключевое различие: **всё это — наблюдение и команды**. Панель не является
маршрутизатором: она не носит трафик, не шифрует его и не «включает VPN». Но команды —
это управление состоянием ядра, и они действительно влияют на маршрутизацию:
переключив узел в группе, вы направите новые соединения через другой сервер;
перечитав конфиг, примените его изменения. Решает по-прежнему ядро; панель лишь
показывает и отправляет то, что API разрешает.

## Что панели нужно для работы

```text
MetaCubeX (страница в браузере)
    │  HTTP API
    ▼
external-controller  (порт 9090 — только если включён)
    │
    ▼
Mihomo
```

Из этой схемы следуют все условия:

1. **controller должен быть включён** в `config.yaml`. По умолчанию в этом проекте
   он выключен — без включения панели просто не к чему подключаться
   (**Проверено в проекте**).
2. **Адрес должен быть правильным** — тот, на котором слушает `external-controller`.
3. **`secret` нужен, если он настроен** — это пароль к API.
4. **`127.0.0.1` в поле панели означает тот компьютер, где открыт браузер** — для
   LAN-сценария используется IP роутера.

Пошаговое включение и подключение — не в этой статье:
[12-pervyj-vhod-v-ui.md](12-pervyj-vhod-v-ui.md). Почему `127.0.0.1` в поле панели —
почти всегда неправильно, и когда оно всё-таки правильно:
[13-127-0-0-1-i-ip-routera.md](13-127-0-0-1-i-ip-routera.md).

## Что будет без MetaCubeX

> **Mihomo продолжает полноценно работать без web-панели** — установка по умолчанию
> этого проекта так и живёт (**Проверено в проекте**).

Проверять и управлять ядром можно и без панели:

- **конфигурацией** — правка `config.yaml` + `S99mihomo restart`
  (**Проверено в проекте** — основной способ проекта);
- **CLI по SSH** — `S99mihomo status`, `mihomo -t`, curl-проверки порта
  (**Проверено в проекте** — см. [10-mihomo-eto.md](10-mihomo-eto.md), «Минимальная
  диагностика»);
- **API напрямую** — например, запрос версии ядра из статьи 12
  (`curl … /version`) (*общее поведение Mihomo*); у API есть и другие запросы —
  разбор позже, в Части III;
- **другой совместимой панелью** — панели говорят с ядром одним и тем же API
  (*общее поведение MetaCubeX-экосистемы*).

## Почему панель показывает `127.0.0.1:9090`

Панели не знают заранее, где работает ваше ядро, поэтому предлагают адрес по
умолчанию — `127.0.0.1:9090`. Но значение этого поля для панели — «**где браузеру
искать API**», а браузер работает на вашем компьютере:

> **`127.0.0.1` в браузере означает компьютер, на котором работает браузер, —
> а не роутер.**

Для домашнего сценария правильное значение — LAN IP роутера. Полный разбор с
схемами и SSH-туннелем: [13-127-0-0-1-i-ip-routera.md](13-127-0-0-1-i-ip-routera.md).

## Панель и безопасность — минимум, который нужно знать уже сейчас

- `external-controller` — это **API управления всем ядром**: через него можно менять
  поведение Mihomo на лету (*общее поведение Mihomo*, проверено по коду ядра).
- Поэтому **бездумно выставлять его наружу нельзя**: «наружу» означает и публичный
  интернет, и любые сети, которым вы не готовы доверять как себе.
- **`0.0.0.0:9090` — более широкий bind** (все интерфейсы сразу), чем LAN-адрес
  роутера; для новичка это не вариант по умолчанию.
- **`secret` обязателен**, когда controller доступен из сети, — это пароль к API.
- Публично доступный controller — **не нормальный beginner-default**, а осознанное
  исключение с отдельными мерами защиты.

Подробный разбор (что именно может API, чем опасны варианты бинда, удалённый доступ)
— позже, в Части III энциклопедии.

## Минимальный сценарий целиком

```text
Keenetic
└── Mihomo
    ├── config.yaml          (/opt/etc/mihomo/config.yaml)
    └── external-controller  (:9090, если включён)

ПК
└── Браузер
    └── MetaCubeX (страница панели)
          │
          │   http://IP-РОУТЕРА:9090/ui/
          ▼
       controller  ──►  Mihomo
```

> **Через эту стрелку идут команды и данные панели, а не весь трафик
> пользователя.** Пользовательский трафик идёт по схеме из
> [10-mihomo-eto.md](10-mihomo-eto.md) и в панель не заходит.
