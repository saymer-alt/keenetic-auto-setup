# KAS Control Center — установка и управление WEB-панелью (beta.2)

**KAS Control Center** — отдельный **необязательный** WEB-компонент KAS: панель управления в браузере для уже установленного KAS. Основной способ установки ядра — [скриптовый KAS](../README.md); панель ничего не заменяет и не переустанавливает: она управляет YAML-конфигом Mihomo, диагностикой Doctor, фильтрами подписок и собственными обновлениями. Без неё KAS полностью работоспособен.

> ⚠️ **Beta.** Возможны изменения; автоматического отката обновлений нет. Доступность панели определяется вашей маршрутизацией и firewall: панель слушает только IPv4-адрес интерфейса br0 и не публикуется в WAN, но если вы сами настроили проброс портов, KeenDNS-прокси без авторизации или доступ из недоверенной сети — вы принимаете этот риск на себя. Пароль поверх обычного HTTP не шифруется; используйте панель только в доверенной сети управления.

**Требования:** Keenetic/Netcraze с установленным Entware (USB или встроенная память), работающий KAS (Mihomo), мост `br0` (сеть управления, не обязательно домашняя) с одним приватным IPv4.

**Архитектуры:** `aarch64-3.10` (KN-1012, KN-3811 и другие ARM64; **KN-1010 — MIPSel (`mipsel-3.4`), не ARM64**), `armv7-3.2`, `mipsel-3.4`, `mips-3.4` — должны совпадать с архитектурой вашего Entware.

**Как узнать архитектуру:** выполните на роутере `opkg print-architecture` (или `uname -m`: `aarch64` → aarch64-3.10, `armv7l` → armv7-3.2, `mipsel` → mipsel-3.4, `mips` → mips-3.4).

**Скачивание и установка** (пример для aarch64; подставьте свою архитектуру):

```sh
cd /tmp
curl -fSsLO https://github.com/saymer-alt/keenetic-auto-setup/releases/download/v0.1.0-beta.2/kas-control-center_0.1.0.beta.2-1_aarch64-3.10.ipk
curl -fSsLO https://github.com/saymer-alt/keenetic-auto-setup/releases/download/v0.1.0-beta.2/SHA256SUMS
grep '  kas-control-center_0.1.0.beta.2-1_aarch64-3.10.ipk
```

Панель стартует **только после явного запуска** (установка сама службу не поднимает). Автозапуск после перезагрузки роутера включается стандартным механизмом init-скриптов Entware автоматически.

**Важно:** проверка SHA256 должна завершиться OK. Не использовать `--force-*` и не продолжать при неполном или отсутствующем хеше. На роутерах с заблокированным GitHub скачайте файлы через доверенный ПК и перенесите SFTP/SCP. В первой пользовательской beta.2 реальная аппаратная приёмка относится к KN-1010 MIPSel, а не ко всем поддерживаемым ABI. Ранее сохранённый порт (например 18081) при обновлении сохраняется.

**Как открыть:** `http://<адрес-роутера-на-br0>:8081` — например `http://192.168.1.1:8081`. Панель по умолчанию слушает IPv4-адрес интерфейса `br0` на порту **8081**; при отсутствии/неоднозначности br0 запуск отклоняется (не привязывается к 0.0.0.0 и WAN).

**Доступ, пароль, порт** — вкладка «Настройки»: порт, режим входа (без пароля / пароль панели / Entware root), смена пароля, переключатель ограничение доступа по подсети br0 (по умолчанию выключен). Дополнительно для продвинутых схем: приватные файлы `/opt/etc/kas-control-center.password` (Basic-auth), `/opt/etc/kas-control-center.proxy-origin` (точный KeenDNS-прокси Origin), `/opt/etc/kas-control-center.home-only` — см. [web/control-center/LAN.md](../web/control-center/LAN.md).

**Вкладки панели:**
- **Обзор** — версии панели/KAS/Mihomo/MagiTrickle, проверка и установка обновлений Mihomo и MagiTrickle, обновление самой панели;
- **Подписки** — список серверов подписок, выбор исключаемых узлов, безопасное применение фильтра через штатный импортёр KAS (без правки YAML вручную);
- **Конфигурация** — загрузка/вставка YAML Mihomo через канонический импортёр (второго Mihomo не создаётся);
- **Диагностика** — запуск `mihomo-doctor.sh` с понятной RU/EN-сводкой;
- **Настройки** — порт, доступ, пароль, ограничение по подсети br0.

**Каналы обновлений панели:** в карточке «Обновление панели KAS» выберите канал — **Бета (experimental)** или **Стабильный** — затем нажмите «Проверить версию панели» и подтвердите обновление. Смена канала сама ничего не устанавливает. Обновления **только ручные**, фонового автообновления нет; после обновления панель кратко недоступна и переподключается сама. Stable-канал появится позже отдельным релизом — до тех пор выбор «Стабильный» честно сообщит, что канал ещё не опубликован.

**Удаление панели:** `opkg remove kas-control-center` (настройки и YAML KAS сохраняются; ядро KAS не затрагивается).

**Ограничения и восстановление:** автоматического отката нет. Если обновление не завершилось — не выключайте питание; панель покажет код (например `PANEL_RECOVERY_REQUIRED`), восстановление через SSH: `sh /opt/etc/init.d/S98kas-control-center stop` при необходимости, проверить `opkg` и запустить `/opt/bin/kas-control-center -recover-panel-update`. При повреждении — переустановка проверенного IPK той же или более новой версии. Не переустанавливайте KAS целиком из-за панели.

 SHA256SUMS | sha256sum -c -
opkg install ./kas-control-center_0.1.0.beta.2-1_aarch64-3.10.ipk
sh /opt/etc/init.d/S98kas-control-center start
sh /opt/etc/init.d/S98kas-control-center status
```
