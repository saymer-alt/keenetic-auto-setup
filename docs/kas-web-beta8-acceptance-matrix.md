## Ручные сценарии (пошагово)

Общая подготовка для каждой архитектуры: Keenetic/Netcraze с Entware; `opkg print-architecture` → выбрать IPK этой архитектуры из [v0.1.0-beta.8](https://github.com/saymer-alt/keenetic-auto-setup/releases/tag/v0.1.0-beta.8) + `SHA256SUMS` из того же релиза; проверить контрольную сумму (см. [26-kas-web-beta-install.md](26-kas-web-beta-install.md)). Перед изменениями — скачать текущий YAML (М12).

- **М1 Установка:** установить IPK → `sh /opt/etc/init.d/S98kas-control-center start` → `status` → открыть `http://<IP>:18080/`. Ожидание: панель открывается, под логотипом `KAS Web v0.1.0-beta.8`, футер содержит source SHA `94eec96…`.
- **М2 Обновление:** с установленной предыдущей панели → «Обновление панели» → «Проверить обновления» → установить `0.1.0.beta.8-1` → убедиться, что версия и порт сохранились, YAML и Doctor доступны.
- **М3 Импорт YAML:** «Конфигурация» → вставить корректный YAML → применить → проверить статус операции; затем заведомо невалидный YAML → ожидание: отказ импортёра, текущая конфигурация не изменена.
- **М4 Перезапуск:** `stop` → `status` = `NOT_RUNNING` → `start` → `status` = `RUNNING` + `PANEL_ADDRESS` с фактическим портом; страница открывается по указанному адресу.
- **М5 Настройки:** сменить язык → перезагрузить страницу (язык сохранён); сменить тему; сменить порт → перезапуск службы → панель на новом порту.
- **М6 Порт:** занять 18080 посторонним слушателем → перезапуск панели → ожидание: автоматический выбор 18081–18090, фактический порт в `status`.
- **М7 Статусы:** остановить Mihomo штатно (`sh /opt/etc/init.d/S99mihomo stop`) → «Обновить» → красный ✕ «Процесс остановлен»; запустить → зелёный ✓; MagiTrickle отсутствует → ✕ «Не установлен».
- **М8 Doctor:** «Запустить Doctor» → итог и находки; у известных watchdog-WARN — отдельные заголовки и подсказки RU/EN; «Копировать отчёт» кладёт текст в буфер.
- **М9/М10/М11:** переключить RU/EN; переключить светлую/тёмную темы (включая системную); открыть с телефона при ширине 320 px — версия в sidebar читается, layout не разваливается.
- **М12 Резервная копия:** «Конфигурация» → «Скачать текущий YAML» → файл совпадает с работающей конфигурацией; дополнительно скопировать `/opt/etc/kas-control-center.settings.json`.
- **М13 После перезагрузки:** перезагрузить роутер → служба автостартует, порт и настройки сохранены, YAML на месте.

## Критерии прохождения

- Ни один шаг не требует ручной правки конфигов вне панели/инициализационного скрипта.
- Все проверки контрольных сумм показывают `OK`; несоответствие — стоп, не устанавливать.
- Цвета и значки совпадают с таблицей выше при обеих темах; «зелёный» только при подтверждённом `running`.
- После обновления и перезагрузки: версии, порт, YAML, Doctor и доступ сохранились; `stale`/ошибки API переводят статусы в нейтральные, а не в зелёный/красный.
