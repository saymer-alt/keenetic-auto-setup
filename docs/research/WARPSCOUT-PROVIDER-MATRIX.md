# WARPSCOUT — публичная справка (без полевых результатов)

Эта страница сохранена для совместимости с существующими ссылками. **Детальная матрица измерений по реальным провайдерам снята с публичной публикации 20.11.2026.**

Комбинации ISP, местоположения, даты, NODE, IP:port, доступности и скорости раскрывают сведения о частных сетях. Детальные исследования теперь доступны только в закрытом контуре проекта авторизованным сопровождающим. **Не публиковать здесь название, адрес или путь внутреннего хранилища.**

## Ограничение публикации

Нельзя помещать в публичные Issue, PR, комментарии, документацию и CI-артефакты идентификаторы пользователей, точные места пользовательских тестов, адреса управления и сочетания ISP × сеть/место × дата × протокол × результат/endpoint/NODE. Сырые отчёты и конфигурации также не публикуются.

Обобщённые или синтетические примеры допускаются только после проверки на отсутствие коррелируемых данных и разрешения владельца. Перенос в закрытое хранилище не означает удаления старого текста из истории Git/GitHub или внешних кэшей.
