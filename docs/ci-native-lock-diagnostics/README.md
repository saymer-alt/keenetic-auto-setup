# Проверка SHA256 и блокировок Entware

Этот офлайн-набор тестов воспроизводит работу проверки целостности загрузок из публичной лаборатории `router-emulator`.

Проверяются: несовпадение старого и нового SHA256; запрет записи повреждённых файлов в кэш; повторная проверка кэша; запрет постороннего источника; отделение HTTP 404/503 от ошибки хеша; ограничение повторов; отказ при некорректных полях индекса.

```sh
python3 tests/ci-native-lock-diagnostics/test_digest_gate_oracle.py
python3 tests/ci-native-lock-diagnostics/oracle_digest_gate.py
```

По умолчанию тесты используют синтетические байты, `tempfile` и поддельный транспорт: сеть, GitHub API, QEMU и реальные устройства не задействуются. JSON-файл в `fixtures/` хранит публичный исторический пример изменения Entware, а **не действующую команду обновления lock-файлов**. Опциональный режим `--lab-source` сверяет поведение с локальным checkout публичного `router-emulator` без скачивания артефактов.

Успех этих тестов доказывает только fail-closed поведение оракула. Он не означает, что актуальные пакеты Entware уже проверены, QEMU загрузился или нативный E2E прошёл. Обновление lock-файлов требует отдельной проверки происхождения и подтверждения SHA256.
